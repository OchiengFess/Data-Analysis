# 📌O.F Real Estate — Customer Care Intelligence Dashboard (Power BI)
A real-world business analyst case project simulating a professional Power BI dashboard for the real estate customer service function. The goal was to transform a raw customer care dataset into dynamic business intelligence that enhances decision-making, team performance, and service quality.

This project showcases:

✅ Power Query-based data cleaning and transformation

✅ DAX measures for performance KPIs, efficiency metrics, and SLA compliance

✅ Visual storytelling through interactive, executive-ready dashboards

✅ Dynamic slicers and cross-filtering for stakeholder-specific exploration

🔧 Tools & Tech
- Power BI (Power Query, DAX, Report Layer)

- Excel CSV as data source

- Custom color palette (personal branding)

- GitHub (for version control and documentation)

📂 Project Structure
1.Data Loading & Transformation

- Performed in Power Query Editor

- Cleaned columns, formatted datetime fields, handled nulls

2.Data Modeling & DAX

- Created a star-schema layout with calculated columns & measures

- Extensive use of DAX for KPIs such as resolution time, SLA breach rate, agent score, and channel share

3.Dashboard Development

- Interactive report view with custom visuals

- Slicers for Status, Category, Year, and Month

- Dynamic visuals with drill-through and tooltip layers

🔍 Visual Modules Completed
1. Support Overview

- Total Cases by Channel

- % of Cases by Status

- Average Resolution Time by Channel

2. SLA Monitoring

- SLA Breach Rate by Channel

- Top 5 SLA Breach Categories

SLA Compliance Trend (last 4 months)

3. Performance & Operational Efficiency

Agent Scorecard (dynamic table)

Resolution Funnel (Open → In Progress → Resolved)

### 📊 Key Insights
📈 High SLA breach rates associated with specific categories and channels

🕒 Avg Resolution Time variance reveals critical improvement areas

🎯 Agent efficiency scores highlight top-performing and underperforming team members

🔀 Dynamic filtering enables custom view for different operational leads

### 🚀 How to Explore
- Open the .pbix file in Power BI Desktop

- Interact with slicers to view trends by channel, category, or month

- Hover or click through visuals to drill into specific KPIs 
- Modify DAX measures in the data model as needed
